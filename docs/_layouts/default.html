{%- comment -%} Docs layout for several tutorials in one repository. Each tutorial lives in its own folder (docs//), and its index.md is the tutorial's home page. The sidebar, breadcrumbs and previous and next links cover only the current tutorial's pages. The header, footer, styles and site search come from the main site (site.main_site, "" on the live site), so the docs look and behave like the rest of it. Front matter, per page: title: the page's name in the sidebar and browser tab nav_order: its position (lower first) parent: the title of its section page, for pages inside a section nav_exclude: true to leave a page out of the sidebar search_exclude: true to leave a page out of the site search and on a tutorial's home page (docs//index.md) only: footer_note: a line for the footer, such as the tutorial's licence issues: optional; where to report a problem, if not this repository's issues og_image: a picture for link previews, as a path under the site Translations: a tutorial's pages in another language live in a folder named after the language inside the tutorial's folder (docs//ja/), with the same file names. _config.yml gives that folder its "lang", and _data/i18n.yml holds the interface text.
